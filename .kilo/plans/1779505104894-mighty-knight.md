# Pagination Implementation Plan for Payroll Tab

## Goal
Add functional pagination to the payroll table in `payroll.html` to improve usability when dealing with large datasets.

## Current State
- The payroll table already has pagination infrastructure:
  - `currentPage` and `itemsPerPage` variables defined
  - `updatePagination()` function exists but only updates info text
  - Pagination controls container (`#paginationControls`) exists
  - Table body (`#payrollTableBody`) renders all data without pagination
- Missing:
  - Actual data slicing in `renderTable()`
  - Pagination controls generation
  - Page change handling

## Changes Required

### 1. Update renderTable Function
Replace the incomplete filtering and add proper pagination:
- Filter payroll data by search term and status filter
- Slice filtered data based on currentPage and itemsPerPage
- Render only the paginated data
- Update pagination info and controls

### 2. Enhance updatePagination Function
- Calculate total pages
- Generate "Previous" button (disabled on first page)
- Generate page number buttons (highlight current page)
- Generate "Next" button (disabled on last page)
- Update info text with current range

### 3. Add Page Change Handler
- Create `changePage(page)` function to:
  - Update currentPage
  - Re-render table
  - Prevent default button behavior

### 4. Event Binding
- Ensure pagination buttons trigger page changes
- Maintain existing search/status filter resets to page 1

## Implementation Details

### Filtering Logic
```javascript
const searchTerm = document.getElementById('searchInput').value.toLowerCase();
const statusFilter = document.getElementById('statusFilter').value;

const filtered = payrollData.filter(p => {
    const emp = allEmployees.find(e => e.id == p.employee_id);
    const employeeName = emp?.full_name || '';
    const matchesSearch = !searchTerm || 
        employeeName.toLowerCase().includes(searchTerm) ||
        p.period.toLowerCase().includes(searchTerm) ||
        p.gross_salary.toString().includes(searchTerm) ||
        p.total_deduction.toString().includes(searchTerm) ||
        p.net_salary.toString().includes(searchTerm) ||
        p.status.toLowerCase().includes(searchTerm);
    const matchesStatus = statusFilter === 'all' || p.status === statusFilter;
    return matchesSearch && matchesStatus;
});
```

### Controls Generation
```javascript
function updatePagination(totalItems) {
    const pageCount = Math.ceil(totalItems / itemsPerPage);
    const infoEl = document.getElementById('paginationInfo');
    const controlsEl = document.getElementById('paginationControls');
    
    // Update info
    const start = (currentPage - 1) * itemsPerPage + 1;
    const end = Math.min(start + itemsPerPage - 1, totalItems);
    infoEl.textContent = `Showing ${start}-${end} of ${totalItems}`;
    
    // Build controls
    let controlsHTML = '';
    
    // Previous button
    if (currentPage > 1) {
        controlsHTML += `<button onclick="changePage(${currentPage - 1})" class="px-3 py-1 rounded-lg text-gray-500 hover:bg-gray-100">Previous</button>`;
    }
    
    // Page numbers
    for (let i = 1; i <= pageCount; i++) {
        if (i === currentPage) {
            controlsHTML += `<button class="px-3 py-1 rounded-lg bg-[#b0303b] text-white">${i}</button>`;
        } else {
            controlsHTML += `<button onclick="changePage(${i})" class="px-3 py-1 rounded-lg text-gray-500 hover:bg-gray-100">${i}</button>`;
        }
    }
    
    // Next button
    if (currentPage < pageCount) {
        controlsHTML += `<button onclick="changePage(${currentPage + 1})" class="px-3 py-1 rounded-lg text-gray-500 hover:bg-gray-100">Next</button>`;
    }
    
    controlsEl.innerHTML = controlsHTML;
}
```

### Page Change Handler
```javascript
function changePage(page) {
    currentPage = page;
    renderTable();
}
```
